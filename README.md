## **Metodo 2**
Installazione & aggiornamento manuale tramite la repository su Github.

1) Scarica il file zip più recente in <a href="github.com/louzhee/LocalizeLimbusIT/releases/latest">releases</a> (**non** il source code).
2) Apri Steam, clicca su Limbus Company e clicca sull'icona dell'ingranaggio a destra.
3) Vai su `Gestisci` > `Sfoglia i file locali`. Apri la cartella `LimbusCompany_Data`. 
4) Se non è presente una cartella chiamata `Lang`, creala (importante, la L **deve** essere maiuscola). Apri la cartella ed estrai lì il contenuto dello zip (cartella `Italiano` e `config.json`).
5) Lancia Limbus Company direttamente da Steam.
